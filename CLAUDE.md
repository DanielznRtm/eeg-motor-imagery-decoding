# Como quero que você trabalhe

- Comece planejando: proponha a estrutura e o plano por fases e espere meu OK.
- Faça uma fase por vez. Ao fim de cada uma: rode o código, mostre os resultados,
  explique em português as decisões técnicas (o porquê, não só o quê) e faça um
  commit com mensagem clara em inglês. Depois pare e espere minha revisão.
- Quando houver uma escolha com trade-off (janela temporal, filtro, normalização,
  arquitetura), apresente as opções e recomende uma.
- Código, comentários, README e commits em inglês. Explicações para mim em português.
- Não invente resultados: todo número do README tem que vir de uma execução real,
  salva em results/.
- Antes de usar MNE, MOABB ou braindecode, confira a versão instalada e a
  documentação, porque nomes de classes e funções mudam entre versões.
